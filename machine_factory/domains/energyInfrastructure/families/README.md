# Candidate capability families

Future machine dispositions must cover: asset/sensor quality and observability; DER generation and inverter capability; storage safety/reserve/carbon inventory; feeder/PCC/protection and power quality; grid-connected/island/black-start/reconnection supervision; critical-load flexibility and service continuity; protocol/time/identity readiness; dynamic cyber-risk and authorization; model/RAG proposal and assurance; and energy/carbon trajectory accounting.

These are proposed design groupings, not changes to the cloned machines' family metadata. WP01/WP04 must map every one of the 187 original definitions to retained/adapted, replaced, split, merged, retired or deliberately shared functionality, with identity/allocation and evidence. No disposition inventory has yet been approved.
