## Collect authority before generating operational advice

P0 sources include authentic NIST/selected lawfully accessed standards and software contracts, plus generic/template utility agreements, topology, OEM-style capabilities, protection/stability/hazard models, calibration/time/quality records and switching/restoration procedures. Generic asset documents and replayable threat/carbon inputs may be used in every case. Actual software execution receipts, model/tool provenance and genuine independent admission approvals remain mandatory when testing their behavior. Optional standards/providers become mandatory only for the capability and site profile selected. Global Ember/IEA reports are planning context, not a live local signal.

Public catalog access is not entitlement to full IEEE/IEC/ISO text. Acquire entitled originals into access-controlled storage, not public Git, and obtain embedding/retrieval rights separately from reading, redistribution or training rights. Keep publisher notices and third-party exceptions. OpenADR/OCA/provider terms need their own review. Step Function DNP3 code/tests/docs are **DO_NOT_INGEST** because its public-source license restricts AI/reference uses; this package records only the exclusion and official license URL. ## Admit sources and preserve extraction lineage

Use AVAILABLE → RECEIVED → EXTRACTED → REVIEWED → INDEXED → RETRIEVAL_VALIDATED states. Each transition requires its own receipt; no success at one stage implies another. Keep immutable original bytes separate from extracts, chunk indexes and embeddings. An accountable reviewer approves publisher authenticity, applicable edition/amendment/effective date, jurisdiction, equipment/firmware/site scope, rights, confidentiality, source precedence and expiration.

Every chunk retains parent SHA-256, physical and printed pages, clause/figure/table locators, surrounding definitions/exceptions, parser/OCR versions, extraction quality and source revision. Verify tables, signs, units and safety qualifiers against rendered originals. Avoid chunking away exceptions or confusing a draft with an adopted requirement. Store normative, guidance, approved site procedure, draft, incident narrative and synthetic evaluation labels explicitly. Source corrections/supersession invalidate dependent conclusions, evaluations and embeddings through a revision/deletion plan.

## Enforce retrieval boundaries before similarity search

Separate public normative guidance, entitled standards, site-confidential operations, security intelligence and synthetic/holdout content. Enforce tenant/site/asset/role/license/source-state filters before search and again on original access; vector similarity cannot grant permission. Embeddings inherit source confidentiality. Return exact revision/page/section and age with every retrieved passage; normative answers cite approved authority or abstain when missing/conflicting. A generic public guide does not override the signed site procedure or local utility agreement; conflicting governing authorities require human engineering disposition.

Retrieved PDF/runbook/feed text is evidence, not an instruction hierarchy or a new tool permission. Quarantine uploads, disable embedded scripts/macros/automatic remote loads, check suspicious directives, and independently review critical amendments. Injection classifiers help triage but do not replace authorization. Never let an agent promote its own answer into trusted operational knowledge or use holdout evaluations as production RAG/training data.

## Query current facts through typed tools

Raw telemetry, provider time series, command logs and real approvals belong in authenticated historian/asset sources. Query bounded windows and return typed values, provenance and freshness; do not trust an old embedding as live state. Keep credentials/private keys/passwords out of all collections. Limit traces, retention and export by data policy. Check regional provider purpose/redistribution rights before storing API output; public parser code does not grant rights to the commercial database. [EIA reuse](https://www.eia.gov/about/copyrights_reuse.php), [Ember data](https://ember-energy.org/data/electricity-data-explorer/), [WattTime terms](https://watttime.org/noncommercial-agreement/).

Before enabling a collection, pass approved-source coverage, page/table fidelity, citation grounding, stale/conflicting-authority abstention, cross-scope denial, malicious-source and deletion/supersession tests. Log actual source/embedding/collection versions and evaluation receipts. The proposed source record template is [here](../../templates/rag-source-record.json); it is not proof of acquisition or permission.
