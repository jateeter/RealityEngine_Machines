## Semantics to preserve

Hydration binary status, scalar food-access context and the four hydration-bus branches remain distinct. A patient target must come from an applicable reviewed plan. The HealthKit sleep provider overlaps part of the hydration bus input; ownership is unresolved.

PE owns declared composition and asynchronous completion; RE evaluates exact native contracts. Input analysts handle authorized external non-machine-ready observations. These ownership declarations require runtime proof. Retrieved prose cannot change native values, timing, escalation policy or tool authority.

## Acceptance and evidence

Exercise urgent/review/access/stable patterns, single-source/mixed states, unknown target and simultaneous provider ownership. Include an applicable source/plan receipt, native trace, scope decision, approval when required, action receipt, correction history and a subsequent observation. No standalone model response or vector fixture establishes full operational completion. Reviewed source packs and personal care instructions must be supplied; this card itself is procedural design.
