Documentary assembly only; original machine names and canonical families remain unchanged. Covered machines: `MedicationAdherenceMonitor`, `HomeMedicationCostBarrierMonitor`, `MedicationAccessAdherenceInterconnect`. Exact paths, hashes, projections, lanes and buses come from [the semantic inventory](../semantic-inventory.json).

## Desired contribution

Use the [core interaction template](../templates/interaction-guidance.md) to qualify observations, explain supported context, propose manageable support and record actual outcomes. The group's owner contributes to one subject/window plan and requests changes to another owner's assets rather than overwriting them.

## Semantics to preserve

A reminder is not ingestion. Current medication axis2 label says missed-past-grace but literal [0,1] is on-time GREEN and [1,1] missed RED; preserve executable meaning and require label reconciliation. Cost and transport barriers are distinct from administration.

PE owns declared composition and asynchronous completion; RE evaluates exact native contracts. Input analysts handle authorized external non-machine-ready observations. These ownership declarations require runtime proof. Retrieved prose cannot change native values, timing, escalation policy or tool authority.

## Acceptance and evidence

Test authentic confirmation, pending/missed ambiguity, access barrier and applicable approved schedule; no autonomous dose changes. Include an applicable source/plan receipt, native trace, scope decision, approval when required, action receipt, correction history and a subsequent observation. No standalone model response or vector fixture establishes full operational completion. Reviewed source packs and personal care instructions must be supplied; this card itself is procedural design.
