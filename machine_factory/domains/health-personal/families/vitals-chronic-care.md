## Desired contribution

Use the [core interaction template](../templates/interaction-guidance.md) to qualify observations, explain supported context, propose manageable support and record actual outcomes. The group's owner contributes to one subject/window plan and requests changes to another owner's assets rather than overwriting them.

## Semantics to preserve

Preserve measured continuous4D vitals input and machine-defined binary output, not an LLM-generated binary input. Native normalized codec ranges are not individualized clinical targets. Chronic disease uses scalar inputs and distinct response branches.

PE owns declared composition and asynchronous completion; RE evaluates exact native contracts. Input analysts handle authorized external non-machine-ready observations. These ownership declarations require runtime proof. Retrieved prose cannot change native values, timing, escalation policy or tool authority.

## Acceptance and evidence

Test units/codec, confidence, threshold-side matching, simultaneous matches, source validity and acute/access/preventive/stable branch distinctions. Include an applicable source/plan receipt, native trace, scope decision, approval when required, action receipt, correction history and a subsequent observation. No standalone model response or vector fixture establishes full operational completion. Reviewed source packs and personal care instructions must be supplied; this card itself is procedural design.
