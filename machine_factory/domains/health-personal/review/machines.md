# Personal Health machine semantics and completeness

## What exists, and which meanings must the asset package preserve?

### Takeaway
Personal Health's canonical slug is `health-personal`, with 43 machines and 172 CESs, including genuinely different binary, scalar, ordinal and threshold contracts. This domain is not a copy of LifeBalance's 100-template dispatcher structure; all required manifest machine classes are represented. No runtime machine source was modified.

### Cited Findings
- Manifest calls the domain Personal Health, slug `health-personal`, expected count43, supervised-act default and HealthKit/local-device source pattern. Required classes are sensor-preaggregator/signal-monitor/risk-forecaster/agent-dispatcher/outcome-stabilizer. — [domain-manifest.json](https://github.com/jateeter/RealityEngine_Machines/blob/7d9bf071a8f1f28355712dd7633ed870302b3783/domains/domain-manifest.json#L30)
- Exact inventory: 17 bridges,15 signal monitors,6 risk forecasters,2 outcome stabilizers,1 sensor preaggregator,1 safety-compliance checker,1 agent dispatcher. All43 declare PASSTHROUGH;23 machine-level gte,19 equals,1 uses element threshold comparators. 24 OpenClaw projections =14 machine-native-binary,9 machine-native-scalar,1 machine-native-ordinal;19 have no projection. This is measured from all files below, not manifest inference.
- Core ontology distinguishes CES/steps, determinations, trigger rules, logging/notification/escalation/automation actions and PROV-style audit concepts. A CES is an ordered regular-expression recognizer, not an LLM-generated clinical conclusion. `RagStatus` means Red/Amber/Green, not retrieval augmented generation. — [re-core.ttl](https://github.com/jateeter/RealityEngine_Machines/blob/7d9bf071a8f1f28355712dd7633ed870302b3783/semantics/ontology/re-core.ttl#L26) ; [re-core.ttl](https://github.com/jateeter/RealityEngine_Machines/blob/7d9bf071a8f1f28355712dd7633ed870302b3783/semantics/ontology/re-core.ttl#L81)

### Inferences
- Use a single source-hashed semantic inventory plus documentary capability grouping; keep original tagging.family unchanged. Treat sensors, analysts, deterministic recognizers, PE composers, localAI resolvers and effectful action workers as separate stages.
- Extend documentary evidence, authorization and feedback semantics alongside native semantics, not by silently replacing vectors, arbitration, source lanes or consequences.

### Gaps
- Static metadata and OWL parity do not establish clinical validity, live PE composition, model execution, external responder acknowledgement or deployed privacy enforcement.

## Which conflicts and incompleteness need explicit preservation and review?

### Takeaway
The machine inventory is structurally more complete than LifeBalance, but declared semantic labels and narrative examples contain drift. Preserve the executable baseline as-is and track reconciliations as proposed changes with dedicated tests, rather than making the asset prose silently fix it.
