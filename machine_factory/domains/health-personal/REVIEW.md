# Personal Health completeness and agentic integration review

Reviewed 2026-10-28. Canonical domain: `health-personal`. **Personal Health has substantial native recognition and ingestion foundations, but complete agentic care workflows remain unverified and contain confirmed configuration/semantic conflicts.** Preserve its existing mixed representations and temporal behavior; do not replace them with a generic wellbeing score.

This package documents the desired full operating environment and adds procedural evidence, authorization, artifact lifecycle and outcome semantics alongside native contracts. It changes no machine JSON, runtime comparator, threshold, mapping, trigger, ontology or source policy. The [source-hashed inventory](semantic-inventory.json) is the preservation baseline. Detailed evidence is in the [machine review](review/machines.md) and [integration review](review/integrations.md); [revision provenance](review/provenance.json) bounds the review.

## Priority findings and proposed work

1. **P1 — Resolve source ownership and shared-lane semantics.** HealthKit sleep writes four continuous values at4340; the hydration bus consumes4336–4345, with overlapping fields representing compact sleep/food status. This is a confirmed static semantic collision, not an observed overwrite. Demonstrate correct composition with simultaneous sources before acceptance. The bridge also lacks a raw fall-motion producer at4300. See PH-A02–04 in [the acceptance matrix](acceptance/cases.json).
2. **P1 — Reconcile completion IDs, response vocabulary and native projections.** Named mappings and pointer lists disagree. Some axes are conditional bits; medication axis2 is labeled missed-past-grace despite on-time [0,1] semantics. HomeSocialIsolation calls a status-bit projection scalar. Correct through explicit reviewed adapters/tests, never by guessing labels or replacing native values. See PH-A05–07.
3. **P1 — Prove action execution, authorization and durable acknowledgement.** The inspected C++ terminal path records dispatches; localAI GraphQL stores a bounded event log. These functions do not execute a provider/action worker. A separately deployed consumer was not ruled out, but needs a trace. Validate exact-revision scope/approval, tool receipts, retries, restart and actual follow-up. See PH-A10–12.
4. **P1 — Preserve urgent response independently of generation.** Recognition and configured urgent routing must not wait for RAG/model availability. Resolve source validity, timing, operational response contacts and acknowledgement policies; example.org destinations and inconsistent declared response timings need owned review. The package supplies no new clinical thresholds or emergency policy.
5. **P1 — Strengthen existing RAG rather than invent a second competing seed.** Keep health_search and reconciliation, add source review, population/context applicability, authorization filters, exact passage/hash/index receipts, revocation and contradiction/injection tests. Existing nutrition prose contains numerical advice without established qualified provenance. Do not promote it into approved care instructions. See PH-A08–09.
6. **P2 — Repair narrative/source drift and expand truth-table coverage.** PatientSafetyTransport narrative cites output3827 while canonical output starts7378; transport vocabulary also differs. All exact-match buses need isolated/mixed/unknown/stale cases, not only their four example patterns. Existing source meaning remains unchanged pending reviewed fixes. See PH-A06 and PH-A13.

## Semantics carried into the operating environment

Fall motion/stillness and tier/confidence retain distinct ordinal ranges and ordered CES paths; a RED label is not a confirmed injury. The count preaggregator supplies motion, not a stillness source. A declared one-tick relationship does not mean synchronous same-cycle composition.

Continuous measured HealthKit codecs retain units, provenance, confidence, clamping and freshness; codec ranges are not clinical targets. Removed source means absent, while a locked source may hold older values. The raw bridge→PIM→owner POD mirror is a separate, partially implemented contract; PIM is the sole POD writer under that contract. Raw records never become universal-vector payloads.

PE owns declared input presence/composition and asynchronous dispatch; RE evaluates native CESs. Those ownership declarations need runtime verification. Analysts can qualify permitted non-machine-ready context but cannot overwrite upstream outputs or convert a machine observation into a clinical fact, approval or completed action. Red/Amber/Green status is distinct from retrieval-augmented generation despite the shared abbreviation.

The documentary extension adds one accountable owner per artifact, immutable revisions, exact evidence references, authenticated decision boundaries, dependency-driven staleness and observed outcomes. Ten guidance groups are documentary assemblies only; original names and canonical families are preserved.
