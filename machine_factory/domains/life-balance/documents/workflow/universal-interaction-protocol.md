# Universal interaction protocol

Apply the [interaction template](../../templates/interaction-guidance.md) with the relevant family card. The same contract governs nutrition, sleep, movement, stress, care, family, monitoring, connection and outcomes.

1. Resolve identity/scope at the gateway, intent, current plan and consent. A name string is not identity proof.
2. Inspect current immutable document heads and observations. Resolve missingness, units, freshness and context.
3. Retrieve applicable reviewed passages and authorized personal evidence separately. Save a reproducible evidence receipt.
4. Ask the LLM to assess and draft within evidence and permitted action scope; validate schema, citations and deterministic calculations.
5. Translate eligible signals through the explicit machine adapter. A CES output creates an assessment/proposal task, not a clinical fact or approval.
6. Obtain approval/review required by the action and exact artifact revision. Enforce at the tool gateway.
7. Execute once, validate the completion, persist the receipt and expose status.
8. Observe subsequent experience, correct records and reassess dependent plans. Track benefit and burden separately from technical success.

If the user asks to explain, correct or stop, perform that purpose directly. Do not convert every interaction into an action. Cross-family disagreements create one owned reconciliation task; agents must not silently overwrite each other's plans. Constraints and care instructions require reviewed resolution rather than a universal ranking that claims to settle all clinical conflicts.
