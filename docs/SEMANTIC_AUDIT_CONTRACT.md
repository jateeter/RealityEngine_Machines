# Semantic Audit Contract

**This file is a pointer. The contract lives in `RealityEngine_CI`.**

    RealityEngine_CI/docs/SEMANTIC_AUDIT_CONTRACT.md

Do not edit this file, and do not copy the contract back into this repository.
Edit the master in `RealityEngine_CI` instead.

## Why this is a pointer

Governance contracts bind every runtime — the C++, LSP and Scala engines, the
TypeScript Perception Engine, and the CI verification lanes. A contract that
several repositories implement should have one home, and that home is
`RealityEngine_CI`, alongside `SURFACE_SPEC.md` and `DEPLOYMENT_CONTRACT.md`.

Splitting governance across two repositories meant a reader had to know which
one to look in, and it left no single place to check whether a contract had
changed. `SURFACE_SPEC.md` demonstrated the failure mode of the alternative:
kept as a canonical copy plus three duplicates, two correct parallel edits
described the same rule in different words and turned `main` red.

This corpus repository still owns what it is authoritative for: the machine
definitions, schemas, triggers and the tests that gate them. It no longer owns
the contracts that other runtimes implement.

## Citations elsewhere are unaffected

Nothing reads these files by path — every reference across the repositories is
a prose citation in a comment or docstring, of the form
`SEMANTIC_AUDIT_CONTRACT.md §5`. Those remain correct; only the file's home moved.
